# app-template（授業アプリのひな形）

新しいアプリはこのリポジトリをコピーして作ります。パソコンにファイルを置く必要はありません。

## 新しいアプリを作る
- **Claude に頼む**: 「app-template から ○○ という新しいアプリを作って」
- **自分で（スマホ可）**: このページの緑の「Use this template」→「Create a new repository」→ 名前を入れて作成 → Settings → Pages で `main` / `/(root)` を選んで保存

## 外出先から直す（claude.ai/code）
1. スマホやPCのブラウザで claude.ai/code を開く
2. リポジトリを選んで、直したいことを書いて送る
3. Claude が直してプルリクエストを作る
4. 内容を確かめて「Merge」を押す → 数分で公開ページが新しくなる
